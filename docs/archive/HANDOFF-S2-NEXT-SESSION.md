**必须遵守（都是踩过的坑，别再犯）**：
- 长任务一律**后台跑 + 日志落盘**到 `.buildlogs/`。**前台长命令会被用户消息打断且数据全丢**（§234）；串口录制要**边读边 flush**。
- **同一时刻只允许一个构建**：动手前 `pgrep -fl "build-tab5-skin.sh|idf.py"`，有残留先杀干净；构建目录被并发踩过就删掉全量重编（"编成功但产物被踩"比"编不过"危险得多）。串口同理**只允许一个读端**。
- 刷机前必须断言"刷的就是刚编的"：`mktemp` marker + `find -newer` + 打印 sha256；分区表相关改动先跑 `python3 tools/check-dual-partition.py <merged.img>`（三副本一致性门禁）。
- 动设备统一用 `tools/flash-tab5-dual.sh <竖屏merged> <横屏件目录>`（自带门禁 + sha 断言 + 读回核对 6 槽 + 把引导槽设回竖屏）；刷写异常时加 `FLASH_BAUD=460800 FLASH_NO_COMPRESS=1`。
- 方向选择**不是存 NVS**，而是落盘 SD 卡 `/sd/retro-go/config/ui.json`（namespace `ui`，key `orient`）；"设备实际方向"永远以**运行分区标签**为准（`rg_orient_running()`），不要用 `rg_orient_get()`（那是"用户的选择"）。
- 比较"方向"时一律用**实际方向**；用户取消/返回必须原样传出 `RG_ORIENT_UNSET(-1)`，绝不能伪装成"选了竖屏"。
- 夜间自动化礼仪（用户逐字许可）：**测前静音、用完关机**，设备随我测试、不需逐次确认。
- 改 GUI 必须先用**固件同源渲染**出图给用户看（`tools/preview-touch-overlay.py` 出底图 + 固件里的几何/配色常量）；他这次豁免了"重启过渡屏"这一处，别再自行豁免。

**已知残留（用户已接受，不要再动）**：切换重启瞬间面板会闪一瞬蓝 —— 属 DSI/面板复位期状态，不是本工程绘制的画面（`rst:0xc (SW_CPU_RESET)` + 无 panic 已证）。
